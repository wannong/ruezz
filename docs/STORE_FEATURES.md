## 分条完整版（若字段支持多条、每条 ≤200 字）

### 简体中文（zh-CN）

1. 本地科研文献知识库，数据保存在你指定的文件夹  
2. 拖入 Markdown、PDF、Word 等，整篇归档为文献页  
3. 文献库分类与文件夹组织（含未分类）  
4. LLM Wiki：原件进 raw/，可读页面进 wiki/，索引可重建  
5. 基于本地库的 Agent 对话与工具调用  
6. 将选中原文「加入对话」，快速引用到提问框  
7. 知识页 / PDF / Agent 回复上的便签式 Idea 批注  
8. Idea 可折叠、统一显隐，并支持检索与回看  
9. 页面浏览、搜索与知识图谱导航  
10. 自备 OpenAI 兼容 API（BYOK），多服务商与模型切换  
11. 安装包自带运行环境，无需另装 Node、Python、Git  
12. 当前用户安装，一般无需管理员权限  

### English (en-US)

1. Local research literature vault—files stay in a folder you choose  
2. Drag and drop Markdown, PDF, Word, and more as full literature pages  
3. Library folders and categories (including uncategorized)  
4. LLM Wiki: originals in raw/, readable pages in wiki/, rebuildable indexes  
5. Agent chat grounded in your local library with tool use  
6. “Add to chat” from selected text to quote into the composer  
7. Sticky Idea notes on wiki pages, PDFs, and agent replies  
8. Collapsible Ideas with show/hide and search/revisit  
9. Page browsing, search, and knowledge-graph navigation  
10. Bring-your-own OpenAI-compatible API with multiple providers/models  
11. Bundled runtime—no separate Node, Python, or Git install  
12. Per-user install; administrator rights usually not required
