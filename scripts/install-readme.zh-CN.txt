Ruezz（瑞知）安装说明（给没有开发环境的电脑）

不需要安装 Node、Python、Git，也不需要管理员权限。

1. 双击 release 目录中的 Ruezz_<版本>_x64-setup.exe
2. 语言选中文，一直点下一步
3. 装完后从开始菜单打开 Ruezz
4. 第一次运行会让你选一个文件夹当知识库（例如 文档\我的Wiki）
5. 打开设置，填入可用的 AI 接口地址和密钥后即可提问、入库
6. 之后可在「设置 → 关于与更新」检查并安装新版本（需联网访问 GitHub Releases）

系统要求：64 位 Windows 10 或 11。若系统已有 Edge/WebView2 会直接使用；没有的话第一次打开会下载到用户目录，不需要管理员权限。
升级时一般不必先卸载：运行新安装包，选择不卸载、直接安装即可。
