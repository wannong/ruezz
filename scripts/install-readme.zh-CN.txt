WikiHome 1.0.5 安装说明（给没有开发环境的电脑）

不需要安装 Node、Python、Git，也不需要管理员权限。

1. 双击 WikiHome_1.0.5_x64-setup.exe
2. 语言选中文，一直点下一步
3. 装完后从开始菜单打开 WikiHome
4. 第一次运行会让你选一个文件夹当知识库（例如 文档\我的Wiki）
5. 打开设置，填入可用的 AI 接口地址和密钥后即可提问、入库

系统要求：64 位 Windows 10 或 11。安装包已内置网页组件（WebView2），不依赖系统是否另外装过 Edge/WebView2，也不需要管理员权限。

绿色目录（本文件夹里的 WikiHome.exe）给开发机快速打开用，普通电脑请用上面的安装包。
